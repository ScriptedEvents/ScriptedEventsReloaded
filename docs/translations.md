# Translation policy

The previous GitBook repository contains partial German and Italian tutorials.
They were written for an older language revision and do not cover the complete
1.0 workflow, so copying them into the main navigation would mislead new users.

English is the canonical documentation until a translation is:

1. based on the current files in `docs`;
2. complete for the beginner path;
3. checked for current commands, method names, and examples;
4. assigned a maintainer who can update it when the canonical page changes.

A translated tree should mirror the paths in `docs` and state the commit or
documentation revision it was synchronized with. Machine translation may help
draft prose, but code, commands, filenames, and SER terminology must be reviewed
manually.
